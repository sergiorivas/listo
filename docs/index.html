How it works

One file, three ways to look at it.

Switch views without switching files. Every checkbox, subtask and note is the same underlying Markdown — Listo just renders it differently depending on how you want to work right now.

Kanban, for moving work along

Sections become columns. Drag a card, check it off, collapse a column you're not looking at. Each heading in the file — # To Do, # In Progress — is a column here, nothing more configured.

✓ Resizable, collapsible columns with live task counts
✓ Drop a card on another to reorder it or nest it as a subtask
✓ Subtasks nest one level under a task
✓ Notes preview right on the card

Outline, for reading it top to bottom

The same sections and tasks, laid out as one scrollable document with real typographic hierarchy — closer to how the file actually reads. Good for reviewing everything at once, or on a smaller window.

✓ Full note text shown inline, no click needed
✓ Same keyboard shortcuts as Kanban
✓ Fold any section, accordion-style

Things‑style keyboard control

Select a row and drive it from the keyboard: Space checks it off, ⇥ / ⇧⇥ indent and outdent, ⌘↑ / ⌘↓ reorder, ⌘← / ⌘→ move it to the next column. Right‑click for the rest. Every action can be undone with ⌘Z.

✓ Selection follows you between views
✓ Multi‑select with ⇧↑ / ⇧↓, then act on all of them
✓ A task may carry a note; a subtask stays simple
No proprietary format

It's just Markdown. Really.

Every list Listo shows you is a plain .md file on disk — the same one you could open in TextEdit, sync with iCloud or Dropbox, or edit from any other machine. Nothing about it is Listo‑only.

# To Do - [ ] Design the onboarding flow #design !! - [ ] Sketch the welcome screen - [ ] Write the empty-state copy - [ ] Renew the domain @2026-11-15 !!! # In Progress - [ ] Rebuild the settings panel Keep the API key field last — most people skip it on first run, and it shouldn't block getting started. # Done - [x] Ship dark mode - [x] Fix crash on empty file open

Prefer to type directly? Free Mode gives you the raw text with syntax highlighting — no watcher fighting your edits, no auto‑formatting while you type. Listo only re‑reads the file when you save, so pasting or typing fast never gets reverted out from under you.

Type it, don't configure it

Structure that lives in the text.

Priorities, due dates and tags are just characters in the title. Type them anywhere — the board turns them into badges, and the file stays readable in any editor.

!, !! or !!! at the end of a line. Higher priorities float to the top; your file order is never rewritten.

Due dates

Type @tomorrow or @fri and it becomes the real date. Shown as a badge that turns red when overdue.

Tags

Become chips on the card. Click one to filter the board down to just that tag.

Search & filter

Search titles and notes, or narrow by state, priority, due date or tag. Filtering only hides rows — the file is never touched.

Built for how a list actually gets used

Small, deliberate scope.

Two levels, on purpose

A task can carry one note and a set of subtasks. Subtasks stay simple — no infinite nesting to get lost in.

Local files, no account

Listo opens and saves ordinary files. Put them in iCloud Drive, a git repo, or nowhere special — it doesn't care.

An LLM only if you bring one

Edit Free Mode text in a way that's genuinely ambiguous, and Listo can ask an LLM to reconcile it — using your own API key. Skip Settings entirely and it just logs the change as unresolved.

Capture from anywhere

Press ⌃⌥N in any app — or use the optional menu‑bar box — and the task lands in your list's first section, ready to sort later.

A readable history

Every change is appended to a plain JSONL log next to your file — completed, moved, renamed, undone. Browse it in the app or export it.

Native, not wrapped

A real SwiftUI app — window tabs, Open Recent, ⌘+/⌘− for font size, light and dark mode, in English or Spanish.

Install

Three commands, via Homebrew.

Listo is free and distributed through a Homebrew cask that drops Listo.app straight into /Applications. No App Store, no account.

$brew tap sergiorivas/tap
$brew trust --cask sergiorivas/tap/listo # third-party tap
$brew install --cask listo

Update later with brew upgrade --cask listo. Requires macOS 14 or later.
