How it works

One file, three ways to look at it.

Switch views without switching files. Every checkbox, subtask and note is the same underlying Markdown — Listo just renders it differently depending on how you want to work right now.

Kanban, for moving work along

Sections become columns. Drag a card, check it off, collapse a column you're not looking at. Each heading in the file — # To Do, # In Progress — is a column here, nothing more configured.

✓ Resizable, collapsible columns
✓ Subtasks nest one level under a task
✓ Notes preview right on the card

Outline, for reading it top to bottom

The same sections and tasks, laid out as one scrollable document with real typographic hierarchy — closer to how the file actually reads. Good for reviewing everything at once, or on a smaller window.

✓ Full note text shown inline, no click needed
✓ Same keyboard shortcuts as Kanban
✓ Rename a section right from its heading

Things‑style keyboard control

Select a row, then ⇥ / ⇧⇥ to indent or outdent, ⌘↑ / ⌘↓ to reorder, ⌘← / ⌘→ to send it to the next column, Space to check it off. ⇧↑ / ⇧↓ select several at once; ⌘G groups them into one task, ⌘T splits a task back into its subtasks. Right‑click for the rest.

✓ Selection follows you between views
✓ Context menu on every row
✓ A task may carry a note; a subtask stays simple
No proprietary format

It's just Markdown. Really.

Every list Listo shows you is a plain .md file on disk — the same one you could open in TextEdit, sync with iCloud or Dropbox, or edit from any other machine. Nothing about it is Listo‑only.

# To Do ## not required — a task is a checkbox line - [ ] Design the onboarding flow - [ ] Sketch the welcome screen - [ ] Write the empty-state copy # In Progress - [ ] Rebuild the settings panel Note: Keep the API key field last — most people skip it on first run, and it shouldn't block getting started. # Done - [x] Ship dark mode - [x] Fix crash on empty file open

Prefer to type directly? Free Mode gives you the raw text with syntax highlighting — no watcher fighting your edits, no auto‑formatting while you type. Listo only re‑reads the file when you save, so pasting or typing fast never gets reverted out from under you.

Everyday features

Type it, and it shows up right.

Priorities, due dates and tags are just a few characters in the task's title, so they survive any editor that touches the file. Listo turns them into badges on the board.

Renew passport !!! Dec 1 #admin

Priority, dates and tags in the title

! to !!! sets a priority and the board sorts by it. @2026-12-01 is a due date that turns red when it's overdue. #admin is a tag; click it to filter.

Quick add from any app

Press ⌃⌥⌘T anywhere and a small panel drops from the menu bar, showing your first column's top tasks and a field to add one. Esc closes it. You can change the shortcut.

Deleted “Book flights” Undo

Undo everything

Every board action can be undone with ⌘Z: deletes, moves, priority changes, splits and groups. After a delete, an Undo button shows up for a few seconds.

Search and filter

⌘F searches titles and notes. The filter menu narrows by state, priority, due date or tag. Filtering only hides rows and never touches the file.

Drag to reorder or nest

Drop a card on the edge of another to put it before or after it, on its middle to make it a subtask, or on a column to move it there. Moved cards slide to their new spot.

Shortcuts for the rest

⌥⌘1–⌥⌘3 set a priority, and ⌘1 / ⌘2 / ⌘3 switch between Kanban, Outline and Free Mode. Settings lists all of them.

Built for how a list actually gets used

Small, deliberate scope.

Two levels, on purpose

A task can carry one note and a set of subtasks. Subtasks stay simple — no infinite nesting to get lost in.

Local files, no account

Listo opens and saves ordinary files. Put them in iCloud Drive, a git repo, or nowhere special — it doesn't care.

An LLM only if you bring one

Edit Free Mode text in a way that's genuinely ambiguous, and Listo can ask an LLM to describe it in the history log, using your own Anthropic or OpenRouter key (Settings has a Test connection button). Skip Settings entirely and it just logs the change as unresolved.

Native, not wrapped

A real SwiftUI app — window tabs, Open Recent, ⌘+/⌘− for font size, light and dark mode, in English or Spanish.

Install

Three commands, via Homebrew.

Listo is distributed through a Homebrew cask. It's an ad‑hoc signed build, not notarized by Apple, so there's no App Store and no Developer ID fee passed on to you. The cask clears the quarantine flag for you. Requires macOS 14 Sonoma or later.

Terminal
$ brew tap sergiorivas/tap
$ brew trust --cask sergiorivas/tap/listo // it's a third-party tap
$ brew install --cask listo
Download the latest .zip

Not using Homebrew? Unzip, move Listo.app to Applications, then run xattr -cr /Applications/Listo.app once (or right‑click ▸ Open) so macOS lets an un‑notarized app open.
